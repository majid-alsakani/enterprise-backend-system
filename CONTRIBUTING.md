# Contributing

Report a reproducible problem with expected/actual behavior and revision. Never include secrets or personal data. Keep pull requests focused; add regression tests and run `pytest -q tests` and `ruff check --isolated app api tests`. Update API documentation when endpoints change.

First contributions: typed response models; explicit demo-login documentation; tested readiness after persistence exists. Discuss real authentication architecture before implementation. Reviews value correctness, security and evidence, not reciprocal stars or followers.

See [API reference](docs/API.md) and [measured performance](docs/PERFORMANCE.md).
